# 運動部115揮汗有禮-自動登入助手
本擴充套件旨在協助使用者於運動部「115揮汗有禮」活動期間，自動化填寫登入資訊、管理週次排程提醒，並追蹤活動任務的完成狀態，提供單一且專屬的活動參與輔助工具。

※隱私權政策

本擴充套件（運動部115揮汗有禮自動登入）尊重並保護使用者的個人隱私。本政策說明本套件如何處理使用者的相關資訊。

1. 資料收集與處理
- 本套件提供使用者手動輸入身分證字號、出生日期、手機號碼及排程時間設定。
- 上述資訊「僅」儲存於使用者個人的瀏覽器本機儲存空間（Chrome Local Storage）。
- 本套件完全沒有建置任何外部伺服器或資料庫，不會將您的任何個人資料上傳、傳輸或分享給開發者或任何第三方。

2. 網站存取與資料讀取
- 本套件僅在「https://500.gov.tw/registrant/*」網域生效。
- 讀取內容僅限於該活動頁面的任務審核進度狀態，用於在介面呈現剩餘天數與週次提醒。

3. 資料刪除
- 使用者可隨時在擴充套件介面中修改或清除所填資料。
- 移除或解除安裝此擴充套件時，瀏覽器本機所儲存的全部資料將會立即完全清除。

4. 聯絡方式
若對本隱私權政策有任何疑問，可透過開發者聯絡資訊與我們聯繫。
